# Total cost of ownership model

Compare alternatives using the same route, payload, operating hours, completed trips and analysis period.

## Alternatives
- Keep the petrol EN125 in current condition.
- Convert the EN125, only if legally and technically admissible.
- Buy a suitable factory-built electric motorcycle.
- Change the transport task (trip consolidation, bicycle/cargo cycle, shared service) where relevant.

## Cost categories
Acquisition/donor; design and engineering; fabrication; traction components; battery replacement reserve; shipping/import/tax; charging equipment; electricity/fuel; maintenance; tyres/brakes; insurance; registration/inspection; downtime; recovery; operator labour; training; end-of-life; residual value.

## Core equations
- `TCO = acquisition + conversion + energy + maintenance + compliance + labour + downtime + end_of_life - residual_value`
- `Cost per completed trip = TCO / completed trips`
- `Energy per km = measured energy at charging source / measured distance`

Do not use dashboard range estimates as measured energy. Do not count unpaid labour as zero without labelling it as a subsidy.

## Inputs and evidence
Every input must be a measured local value with date and instrument/source, written supplier quote, official tariff/legal fee, or clearly labelled scenario assumption. Use low/base/high scenarios only where each assumption is visible. Include battery replacement, utilisation, downtime and landed import costs.
